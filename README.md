# Spring Boot MVC JDBC Multi-DB (`spring-boot-mvc-jdbc-multidb`)

API REST para el cierre y gestión de nómina con **Persistencia Políglota**, construida con **Java 21**, **Spring Boot 3.5.16**, **Spring MVC**, **Spring Data JDBC** y **Spring Data MongoDB**.

Diseñada bajo **Arquitectura Hexagonal (Ports & Adapters)**, **DDD** y **CQRS**, integrando cuatro motores de bases de datos diferentes: **PostgreSQL**, **SQL Server**, **Oracle Database** y **MongoDB**.
